**Industry R&D · Part AI Research Center, Tehran · Sep 2020 – Aug 2021.**

I joined Part AI as the R&D engineer responsible for the agricultural-UAV product line.

- **Hardware:** designed and built cooperative quad-copters from scratch.
- **Flight stack:** flight-controller integration on **Pixhawk Cube**; Linux bring-up on **Erle Brain**; ROS integration; consulted across teams on Khadas and NVIDIA Jetson dev kits.
- **AI software:** authored Python AI APIs against **Microsoft AirSim** flight simulator; designed software architecture and class diagrams for the simulation API surface.
- **Computer vision:** implemented YOLO and YOLO-Lite object-detection algorithms on various embedded targets.
- **Process:** designed and ran the team's **Kanban + Scrum** board on GitLab.

**Stack:** Python, ROS, Pixhawk, Erle Brain, AirSim, Docker, Arduino, Linux, Git.
