**Industry R&D · Part AI Research Center, Tehran · Sep 2020 – Aug 2021.**
**Role:** Lead Robotics & API Developer. I led a team of four and worked with the project manager on task definition, purchasing decisions, and team priorities.

- **Robotics:** designed and built cooperative agricultural quad-copters from scratch, including flight-controller integration (Pixhawk) and Linux bring-up (Erle Brain).
- **Embedded vision:** implemented **YOLO** and **YOLO-Lite** object detection on Khadas and NVIDIA Jetson dev kits, and led cross-team consultations on embedded-systems integration.
- **AI software:** wrote Python AI APIs for the **Microsoft AirSim** flight simulator; designed the software architecture and class diagrams for the simulation API.
- **Process:** set up and ran the team's **Kanban + Scrum** board on GitLab.

**Stack:** Python, sensor fusion, MATLAB, Git, Docker, Arduino, embedded systems, IoT, Linux, Scrum / Kanban.
